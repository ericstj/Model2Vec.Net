# Third-party notices

This project implements inference compatible with MinishLab Model2Vec.

## MinishLab Model2Vec

- Project: https://github.com/MinishLab/model2vec
- License: MIT

Model2Vec's Python source was used as the behavioral reference for tokenization,
pooling, unknown-token filtering, truncation, vocabulary-quantization handling,
and normalization.

## Microsoft.ML.Tokenizers

- Project: https://github.com/dotnet/machinelearning-tokenizers
- License: MIT

The managed tokenizer implementation is used for Hugging Face WordPiece, BPE, and
SentencePiece-backed tokenizers.

- Model: https://huggingface.co/minishlab/potion-base-2M
- License: MIT
- Source model: https://huggingface.co/BAAI/bge-base-en-v1.5

The test model is downloaded during test builds and is not redistributed in this
repository. The committed oracle JSON contains embedding outputs generated by the
Python `model2vec` package for regression testing.
